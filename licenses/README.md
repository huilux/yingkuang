# 补充许可正文

`upstream/sources.json` 记录部分依赖包未携带的许可证正文、准确版本、固定上游提交 URL 与 SHA-256。原文保持不变，适用各自许可证，不受项目 MIT 许可替代。

`npm run licenses:collect` 按依赖名称和版本匹配这些文件，校验 SHA-256 后纳入生成的许可材料。升级依赖时重新检查缺项，不能直接沿用其他版本的记录。npm 平台绑定包缺少正文时，只使用同版本父包携带的正文，并记录来源。

selectors 的 crate 声明 MPL-2.0、源文件保留其版权声明；此处补充 SPDX 发布的标准 MPL-2.0 正文。自动收集不替代对实际安装包中原生库、系统库及许可义务的核对。

objc2 系列的上游仅提供许可选择说明，此处同时保留该说明并补充标准 MIT 条款。标准条款中的占位符不是本项目新增的版权声明；实际署名以依赖源码和 inventory 中的上游作者信息为准。生成材料显式列出其 Apple SDK 与署名审查事项，不将正文文件齐全等同于许可审计完成。

## AppImage 打包组件

[来源索引](packaging/sources.json) 固定 GTK 打包脚本、项目 MIT 启动脚本与 type2-runtime 源码版本。受控交付流程替换旧的 `AppRun.wrapped` 二进制及生成钩子，从源码构建静态运行时，并记录实际链接组件的原始源码、补丁、Alpine 配方和声明。

`npm run build:appimage` 生成供核对载荷的预备包；公开交付由发布工作流继续重新封装。图形驱动及 Wayland 客户端使用系统版本，保持与宿主图形栈兼容。流程核对系统文件摘要或 ELF 变换，重现生成缓存，收集同版本 Ubuntu 原始源码与发行版补丁，把原始许可正文放入最终 AppImage。发布技术材料中的 `appimage/` 保存具体产物的来源、源码、配方、摘要与实测结果。

来源索引描述构建输入，最终交付以该版本的完整材料和检查结果为准。构建命令见 [发布指南](../docs/release.md)。
