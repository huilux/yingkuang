# 补充许可正文

`upstream/sources.json` 记录部分依赖包未携带的许可证正文、准确版本、固定上游提交 URL 与 SHA-256。原文保持不变，适用各自许可证，不受项目 MIT 许可替代。

`npm run licenses:collect` 按依赖名称和版本匹配这些文件，校验 SHA-256 后纳入生成的许可材料。升级依赖时重新检查缺项，不能直接沿用其他版本的记录。npm 平台绑定包缺少正文时，只使用同版本父包携带的正文，并记录来源。

selectors 的 crate 声明 MPL-2.0、源文件保留其版权声明；此处补充 SPDX 发布的标准 MPL-2.0 正文。自动收集不替代对实际安装包中原生库、系统库及许可义务的核对。
