# 第一版开发状态

更新：2026-10-04，版本 0.2.0。本文件记录正式 Tauri 应用的当前完成度，原型目录只保留设计依据。

## 已完成

- JPEG/PNG 原生渐进导入，EXIF 参数读取、方向归一化、缩略图与单文件失败隔离；首张完成即可编辑，重复路径跳过解码。
- 当前照片按需加载最长边 4096px 的高清编辑图，列表缩略图和模糊背景分别缓存；原图不可访问时保留缩略图并提示。
- Tauri npm 启动入口自动合并本地地址代理例外，修复代理返回空 502 导致的原生启动白屏；保留原 localhost 存储地址。
- 预览与导出模糊背景统一 linearRGB，照片阴影统一高斯遮罩，CSS 字号转换为原生字体 em 尺寸；增加跨 WebKit/Rust 的像素与文字几何回归。
- 横竖照片各自保存编辑文档；模糊与纯色相框、独立横纵留白、上下左右参数区、圆角和自然阴影。
- 元数据/自定义文字图层，支持 Shift 多选、组合拖拽、键盘微调、精确坐标、参照对齐、横纵等间距、批量字体/字重/字号/颜色/透明度/方向与删除；手动值可恢复原始元数据。
- 画布中心、照片中心、区域中心和区域三等分吸附，吸附时显示带名称的辅助线。
- Konva 固定视口画布：Ctrl + 滚轮锚点缩放、滚轮/空格拖动/中键平移，拖拽结束一次提交与撤销/重做。
- 画布代码按需加载：无照片时不加载 Konva，生产入口 JavaScript 从 661KB 降至 329KB；构建时检查入口体积预算。
- 内置模板可更新，用户模板可另存；当前照片生成模板封面，“应用当前画布到已选”复制尚未保存为模板的编辑内容。
- 顺序批量导出、取消、单项失败隔离和失败项重试；临时文件完成后以禁止覆盖方式提交；重试保留原任务快照。
- JPEG/PNG、原照片像素或指定成品长边、可选小图不放大、质量/压缩级别、命名后缀、重名编号/跳过；进度与结果显示处理时间。
- 基础 EXIF 白名单、GPS 独立开关、输出方向和尺寸修正、输入 ICC 到 sRGB 的真实转换。
- 上次会话渐进恢复，优先显示上次编辑的照片并保持原列表顺序。文件已移动或无法读取时保留其编辑记录与勾选，恢复原路径后重新导入可找回；损坏会话阻止覆盖并提示。

## 已验证

- 0.2.0：小图不放大实际 PNG 输出与预检尺寸一致；计时完成/取消/失败路径、旧设置兼容及偏好恢复通过。见 [导出体验验收](export-workflow-0.2.0.md)。

- 第三轮用户链路验收：Chromium/WebKit 各 17 项通过；批量及元数据撤销、模板最长名称保存/复制/重启、缺失编辑与勾选恢复、存储失败、嵌套弹窗键盘操作。详见 [0.1.3 验收](user-workflow-0.1.3.md)。

- 第二轮可靠性验收：200 张 24MP 横竖混合素材循环导出（JPEG/PNG 各 100 张，1200px），90.18s，峰值 281.5 MiB；写入竞争、磁盘错误、取消边界、重试、PNG EXIF 往返与资源限制检查通过。见 [完整记录](export-reliability-0.1.2.md)。

- 第一轮导出性能验收：36 组 release 成品测试（12 个场景各 3 次）；默认模板原尺寸 JPEG 4.28→2.38s，PNG 11.87→3.65s。生成的 96MP 压力输入三次原尺寸 JPEG 导出中位数 7.51s / 峰值 972 MiB；不替代真实 96MP 原片验收。见 [完整记录](export-performance-0.1.1.md)。
- PNG 三种压缩模式的不透明/透明像素回读与 ICC 检查；背景放大、阴影采样与原算法的逐像素误差检查；最终 WebKit/Rust 预览像素与文字几何回归。
- TypeScript 生产构建。
- Rust 单元与真实照片测试，包括 6000 × 4000 JPEG 导入、EXIF、带文字相框导出、尺寸、方向和 ICC。
- 本机开发构建下，同一 2400 万像素 JPEG 导入从 10.38 秒降至 0.34 秒；Chromium 与 WebKitGTK 通过缩放锚点、渐进导入和会话恢复回归。测量范围与命令见 [性能审查](performance-review.md)。
- Konva 重构覆盖缩放锚点、细小触控板输入、多倍率边缘拖拽、缓存、旋转、吸附、键盘操作、快速松手撤销及桌面会话持久化。WebKitGTK 与 Chromium 回归及真实鼠标验证见 [重构记录](konva-refactor.md)。
- Clippy `-D warnings`、Rust 格式与 Git 差异格式检查。
- Arch Linux 上的 Tauri 原生进程启动。
- release 二进制已成功生成。当前开发机的 AppImage 封装被 linuxdeploy 对 `/usr/lib/vmware` 私有 GTK 库的递归扫描阻断；应用编译和链接本身已完成，正式包改在隔离环境中构建。
