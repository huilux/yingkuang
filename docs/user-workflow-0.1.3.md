# 0.1.3 完整操作链路验收

日期：2026-10-04。分支：`codex/iteration-03-user-workflow`，基于 `v0.1.2`。

## 修复结果

| 场景 | 原有问题 | 本轮行为 |
| --- | --- | --- |
| 弹窗键盘操作 | 模板库焦点留在背景，Escape 无效 | 统一焦点进入、Tab 循环、背景 inert、顶层关闭和返回触发按钮；导出中不意外关闭 |
| 模板名称 | 超过 120 字符保存成功，重启被丢弃；最长名称复制后也超限 | 输入与保存统一校验；副本名称保留后缀且不超限；重复名称明确提示 |
| 批量套用和撤销 | 批量修改没有完整撤销记录，切换照片丢失历史 | 一次撤销恢复所有目标文档和模板关联；切换照片后仍可撤销/重做；手动元数据也可撤销 |
| 缺失原图 | 重启保存时删除缺失照片的排版和文字覆盖 | 保留原路径、文档、模板关联和勾选；恢复原路径后重新导入即可找回 |
| 恢复后的勾选 | 未勾选的缺失照片被重新导入逻辑自动勾选 | 恢复已有照片保持原导出选择，新照片仍默认勾选 |
| 本地存储异常 | 损坏的会话或模板可能被默认数据覆盖 | 原始记录保留，阻止自动覆盖并持续提示；存储空间不足不会使界面崩溃 |
| 模板库语义 | 文件输入无标签，重复 banner | 补充标签并修正标题容器语义 |

## 验证

- `npm run build`：版本一致性、TypeScript、22 项功能检查、生产构建和 1 项入口体积检查通过。
- Chromium 与 WebKitGTK 各 17 项浏览器集成用例通过，覆盖画布、多选、拖动持久化、批量撤销、导出请求和重试、图片加载、渐进导入、恢复、存储异常、弹窗、元数据撤销和模板重启。
- 最后补充的恢复勾选与缩略图等待检查在两个引擎再次通过。
- 缩略图测试原先把“IPC 请求发出”等同于“React 已提交状态”，整组运行时偶发失败。改为等待真实显示状态，保持原图请求未完成，连续 30 次 Chromium 验证通过；产品图片加载代码未因该测试改变。
- 修正既有测试中误选照片勾选按钮、依赖隐藏品牌图层、以数组下标定位图层等过时假设。
- 最小窗口 1100×720 模板库视觉检查通过。浅色主题 axe 4.12.1：0 violation / 0 incomplete；深色主题 0 violation，1 项待人工判定的文字对比度实测 13.51:1。
- 本轮没有修改 Rust 导出算法。原生输出性能、文件安全与元数据证据沿用 [0.1.2 验收](export-reliability-0.1.2.md)。

本机原始记录位于忽略目录 `test-output/`：`webkit-iteration-03.log`、`webkit-iteration-03-final.log`、`chromium-iteration-03-{1,2}.json`、`build-0.1.3.log` 和 `audit/`。

## 验证边界与后续

浏览器的桌面交互使用 Tauri IPC 模拟，不能代替系统文件选择器和安装包验收。损坏数据不会自动修复；会话损坏时本次修改暂不自动保存，模板库损坏时可导出可读取的模板备份。下一轮继续完善原图重新定位及恢复入口。

历史仅在本次运行中保留，最多 80 步；移除照片清空历史，避免撤销重新引入已移除照片。批量修改以一个操作记录所有目标。
