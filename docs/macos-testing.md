# macOS 实机测试

本轮验收版为 `0.5.8-beta.4`，包含同步后的内置默认模板。Apple Silicon 与 Intel 分别提供一个测试 ZIP；ZIP 中含 DMG、检查记录、SHA-256、许可证和原始依赖源码。

测试包采用 ad-hoc 临时签名，未做 Developer ID 签名和 Apple 公证。包内保留上游 Objective-C 绑定的 SDK/署名许可审查事项，尚未结项。本轮通过未发布的 Release 草稿交付，用于收集实机验收结果；公开 macOS Release 仍待分发核对与验收。

## 选择与安装

1. 在「 → 关于本机」记录 macOS 版本和芯片。

   | 关于本机显示 | 选择的测试包 |
   | --- | --- |
   | Apple M1、M2、M3、M4 等 Apple 芯片 | `macos-arm64-test.zip` |
   | Intel 处理器 | `macos-x64-test.zip` |

2. 维护者从 `v0.5.8-beta.4` 的发布草稿下载对应 ZIP 及同名 `-test_SHA256SUMS.txt`，将两者一起交给测试者。朋友无需配置 Node.js、Rust、Xcode 或开发者账号。
3. 将 ZIP 和校验文件放在同一目录，先核对校验和。Apple Silicon 在下载目录的示例：

   ```sh
   cd ~/Downloads
   shasum -a 256 -c yingkuang_0.5.8-beta.4_macos-arm64-test_SHA256SUMS.txt
   ```

   Intel 包将文件名中的 `macos-arm64` 换成 `macos-x64`。应显示 `OK`。

4. 解压 ZIP，打开其中的 DMG，将「映框」拖到「应用程序」。推出 DMG，再从「应用程序」打开映框。
5. 若系统因未公证或开发者身份无法验证而阻止打开，确认来源和校验和后，按 [Apple 官方指引](https://support.apple.com/zh-cn/102445)在「系统设置 → 隐私与安全性」中对该 App 选择「仍要打开」。如提示损坏、包含恶意内容或没有可用的打开选项，停止并记录原文；不要关闭整个系统的安全检查。

## 功能测试（约 15–20 分钟）

准备一张横图 JPEG、一张竖图 JPEG 和一张 PNG，使用有备份的测试照片。

| 步骤 | 检查内容 | 通过条件 |
| --- | --- | --- |
| 首次打开 | 空工作区、标题栏、窗口缩放及最大化 | 提示在中间画布居中，按钮可点击，无界面溢出 |
| 主题 | 点击顶部图标完成一轮，再切到深色 | 按跟随系统 → 浅色 → 深色循环，实际颜色随之变化 |
| 系统主题 | 切回跟随系统，改变 macOS 外观 | 界面自动响应系统的浅色/深色设置 |
| 导入 | 选择照片、导入文件夹、拖入照片 | 三种方式可用，横竖图与 PNG 均可预览 |
| 默认模板 | 在新工作区导入照片，依次查看三个内置模板 | 默认使用「模糊-底部文字」，竖图采用更新后的布局；相机参数和中文可显示 |
| 裁切旋转 | 首次打开工具，旋转 90°、微调角度并应用 | 加载反馈正常，照片方向及选区正确，取消可保留原结果 |
| 编辑 | 移动水印，使用 Command+Z、Shift+Command+Z | 操作、撤销及重做正常，无快捷键冲突 |
| 导出 | 导出当前 JPEG、PNG，再批量导出三张 | 文件可打开，边框、文字、旋转与预览一致，数量与尺寸符合设置 |
| 重启 | 完全退出并重新打开 | 主题、模板选择及照片编辑记录恢复，原照片仍完整 |
| 移除应用 | 退出后将应用移到废纸篓 | 应用不再运行，原照片与导出文件保留 |

如 Mac 上已有个人模板，升级会保留个人修改。验证新内置样式时，可对对应内置模板执行「重置」，此前先导出完整备份；新工作区的默认选择也可能沿用个人设置。

## 维护者构建与下载

同步版本并提交源码后，创建与完整提交 SHA 一致的 `v0.5.8-beta.4` 标签和 Pre-release 草稿，再执行：

```sh
gh workflow run macos-test.yml --ref main -f release_tag=v0.5.8-beta.4
gh release download v0.5.8-beta.4 -p '*macos-arm64-test*' --dir macos-test
# Intel：将上面的 macos-arm64 改成 macos-x64
```

工作流核对版本、签名、架构、DMG 内的 16 份许可文件和可见原生窗口，再上传到已有草稿。草稿不会自动公开。CI 不包含互联网下载后的 Gatekeeper、应用程序目录安装、照片编辑及导出实机验收，这些结果由测试者记录。
