# 0.4.1 模板参数边界验收

## 问题与改动

导入备份只检查数值是否有限，没有检查原生导出的支持范围。负留白、零字号、超范围透明度和简写颜色都能进入编辑器，直到导出才失败。重复图层 ID 还会影响选择与编辑。

- 前端文档校验对齐原生导出的相框、区域、字号、透明度和六位十六进制颜色范围。
- 拒绝空白或重复图层 ID，以及无法表示为原生有限浮点数的坐标。合法的画布外坐标仍可导入。
- 导入错误指出备份中第几个模板存在问题；不会部分导入。
- 同一校验也保护会话与本地模板读取。历史非法记录保留原文并进入已有恢复流程，不自动删除。

## 验证

- 先增加回归测试，旧代码因接受负留白而失败；修复后非法参数矩阵与合法上下边界全部通过。
- Chromium 与 WebKit：第二个模板非法时提示其位置，原模板库不变；换成有效文件后可直接重试并确认导入。
- WebKit 另行回归模板最长名称保存/复制/重启，以及损坏会话、新旧模板库的备份恢复。
- `npm run build`：版本一致、TypeScript、29 项功能测试、生产构建及入口体积预算通过。
- 原生渲染算法未改变，本轮没有重新测量导出性能；性能结论沿用对应版本的独立基准。
