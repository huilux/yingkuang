# 0.3.0 原图重新定位与缺失记录管理

日期：2026-10-04。分支：`codex/iteration-05-photo-recovery`，基于 `v0.2.0`。

## 用户操作

1. 原图移动后，左侧“原图暂不可用”保留原路径与错误原因。
2. 点击“重新定位原图”，选择新的 JPEG/PNG。重复路径或无法读取的文件会被拦截，原记录不改变。
3. 确认框展示照片预览、新旧路径和尺寸。确认后恢复原排版、手动文字、模板关联、勾选和列表位置，并切换到该照片。
4. 之后导出使用新路径；重启恢复仍保留这些编辑。

选择文件或确认框取消都不改动照片记录。旧版本未保存原尺寸时，只显示新尺寸并提示检查排版。新会话保存原尺寸，以便下次比较。用户仍可把文件放回原路径后重新导入。

应用不能仅凭尺寸判断是否为同一张照片，因此展示预览供用户确认；不会因长宽比变化自动覆盖原排版。

## 本轮发现并修复

全部原图缺失时，“清空批次”原先被禁用；混合批次清空也只删除可用照片，缺失记录下次仍会出现。

现在可以移除单条缺失记录，或清空包含缺失照片的整个批次。确认框明确列出缺失记录数并说明编辑将清除。取消保留原数据；确认只改变批次记录，磁盘原图不会删除。
