# 0.5.0 批次筛选验收

日期：2026-10-06。分支：`codex/iteration-10-batch-filtering`。提交：`feat(library): filter photo batches without losing hidden selections`。版本与标签：`0.5.0` / `v0.5.0`。

## 用户操作

- 左侧展开「查找与筛选」，按文件名与横图、竖图、方图组合查找；文件名忽略大小写，兼容全角字符。
- 全选结果、反选结果、取消结果只改变当前可见照片的勾选。总勾选数始终包含隐藏照片，并显示隐藏数量。
- 筛选保持当前编辑照片和全部编辑记录。当前照片被隐藏时有明确提示。
- 导出与移除确认显示筛选外数量；清空批次覆盖整个批次。
- 无结果时解释如何恢复；新照片导入、原图重新定位和清空全部可用照片会清除筛选，防止新增照片不可见。
- 筛选是临时视图，不写入工作记录；长文件名悬停可读完整名称。

## 小窗口修正

展开筛选后，1100×720 窗口的照片列表曾只剩 79px；更矮窗口几乎不可见。上方控件区现在可滚动，并为列表保留 140px。照片列表和底部移除按钮保持可操作，多个错误或缺失提示也不会把它们挤出窗口。
