# 相框外观与布局扩展

后续修订（2026-09-21）：用户反馈逐层轮廓阴影像描边，现已换成带透明边距的轮廓模糊。下文第四轮核验记录是当时结果，不代表最终阴影实现。第一版范围与导出规则见 `v1-scope.md`。

相框类型决定背景如何绘制；模板组合相框外观、照片效果、区域布局和文字样式。底部信息栏、四边排版属于布局模板，可以搭配模糊背景或白色背景。

## 通用与专属参数

| 范围 | 参数 | 扩展原则 |
| --- | --- | --- |
| 通用布局 | 画布比例、左右/上下基础留白、四边参数区尺寸 | 不依赖背景类型 |
| 通用水印 | 元数据来源、手动值、区域归属、局部位置、字体、方向、吸附 | 切换背景时保留 |
| 照片效果 | 圆角、阴影 | 可选效果，模板可设为零 |
| 模糊背景 | 模糊程度、背景亮度 | 仅此类型显示 |
| 纯色相框 | 背景颜色 | 白、黑及其他纯色共用同一类型 |
| 后续纹理背景 | 纹理资源、缩放、平铺、强度 | 单独定义，尚未实现 |
| 后续渐变背景 | 色标、方向 | 单独定义，尚未实现 |

木质实体框、胶片齿孔等带装饰结构的相框，可能还需要装饰层厚度和安全区域；不应把所有类型硬塞进模糊背景的参数中。正式版本可由每种类型声明自己的设置面板与绘制能力，公共布局仍提供照片矩形和水印区域。

## 原型已实现

- `config.frame.type` 支持 `blur` / `solid`，`frame.color` 保存纯色背景值；旧模板缺失该对象时继续使用模糊背景。
- `FrameRenderers` 提供不同背景绘制器，共用照片、阴影和文字绘制流程；预览与导出调用相同背景函数。
- 右侧“相框外观”只显示当前类型的参数。切换类型保留布局以及此前的模糊/纯色设置。
- 新增“纯白相框”内置模板，默认直角、无阴影、深色水印；套用模板会同时替换其布局。只想改变背景时应使用“相框类型”。
- 新增“文字颜色跟随相框”：纯色背景根据亮度选深色或白色，模糊背景默认白色。关闭后可以手动设色。这不是基于照片局部内容的对比度检测。
- 旧字段未声明 `autoColor` 时，白色字段按自动配色处理，其他颜色保留手动模式；新字段显式记录该标记。
- 相框外观随现有模板保存与批量配置复制流程传递。当前仍使用模板版本 2 的可选扩展字段；正式应用应使用明确的版本迁移和类型校验。

## 2026-09-21 核验

- 原来的 `place-items:center` 导致超宽滚动内容向负坐标偏移。复现时滚到最左端，画布左边仍在视口左侧 655px。清除该居中规则后，150% 与 300% 缩放下，左端均位于视口内 32px。
- 在左右基础留白 18%、阴影 32 的场景看到照片外围的浅矩形边界；阴影改为 0 后消失。改用逐层衰减的圆角阴影，同场景复看不再出现该截断边界。选中字段时的区域虚线与淡色辅助底仍是编辑提示，不参与导出。
- 模糊切换为纯色后，四区仍开启，左右基础留白 18% 保留，左区文字 X/Y 仍为 50%，方向仍跟随区域。
- 白底自动文字色为 `#202224`，深色底 `#111111` 自动文字色为 `#ffffff`。
- 保存“纯白四边 · 试用”后刷新并重新套用，纯色类型、白色背景、留白及四区配置恢复。
- JavaScript 语法与 72 组区域几何回归检查通过。以上是原型验证，不代表原尺寸批量导出或原生应用性能验证。
