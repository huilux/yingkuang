# 摄影水印相框桌面应用：需求与交互草案

更新：2026-09-21。本文记录讨论结果，不代表功能已实现。

第一版范围以 [正式第一版范围](v1-scope.md) 为准：补充模板封面替换、批量成品导出、质量/尺寸/元数据等设置，额外功能延后。本文的较早交互建议不自动成为第一版承诺。

## 用户已明确的要求

- 第一版用于电脑，支持 Arch Linux。
- 导入 JPEG、PNG，主要处理摄影照片；偏好模糊背景相框。
- 中央区域是可直接操作的画布。拍摄时间、焦距、光圈、快门、ISO 等水印字段可独立拖动，自由放置。
- 支持自动吸附，包括水平、垂直居中。
- 水印文字可以修改字体。
- 修改位置、文字和样式时实时预览。
- 可以保存模板，批量添加水印相框。
- 横图与竖图会混在同一批处理。
- 拍摄参数缺失时允许手动补充。

## 建议采用的交互（尚未逐项确认）

### 工作区

- 顶部：导入、撤销/重做、对齐、保存模板、应用样式、导出。
- 左侧：模板库与图层列表，通过标签切换。
- 中央：作品画布、缩放、适应窗口、选框与参考线。
- 右侧：跟随当前选中对象显示属性；提供拍摄信息入口。
- 底部：照片缩略图带、多选、横竖方向、单张调整和排版异常标记。

### 选择与直接编辑

- 单击选择元素，拖动移动；Shift 点选或框选多个元素。
- 多选后可以整体移动、对齐、分组；组内仍保留独立的参数字段。
- 双击文字进入编辑。动态字段修改默认为当前照片的显示覆盖值，字段绑定仍保留。
- 方向键移动 1 个设计单位，Shift 加方向键移动 10 个设计单位；坐标面板提供精确输入。
- 背景与照片默认锁定，可在图层列表显式解锁；水印可放在照片内或边框上。
- 空格加拖动平移视图，缩放视图不改变作品布局。
- 拖动完成或一次文字编辑完成记为一个撤销步骤，避免逐次鼠标移动堆积历史。

### 右侧属性

| 选择对象 | 属性 |
| --- | --- |
| 无元素选中 | 画布比例、留白、模糊背景、亮度、饱和度 |
| 主照片 | 位置、尺寸、保持宽高比、圆角、描边、阴影 |
| 单个水印字段/文字 | 字段来源、当前值、字体、字重、字号、字距、颜色、透明度、坐标与锚点 |
| Logo | 素材、位置、等比尺寸、透明度 |
| 多个元素/分组 | 共同属性、对齐、间距分布、组合与取消组合 |

修改实时反映到中央预览。拖动期间复用模糊背景缓存，预览使用缩小图；导出使用原图和同一套布局计算。字体加载完成后重新测量文字，导出前等待字体及图片素材就绪。

### 吸附与对齐

- 吸附目标：画布边缘与中心、照片边缘与中心、留白区域中心、其他元素边缘/中心/文字基线。
- 接近目标时显示辅助线与适当的距离标注；吸附阈值使用屏幕距离，避免缩放改变手感。
- 吸附可关闭；具体临时绕过快捷键需在 Arch 桌面环境中验证，避免与窗口管理快捷键冲突。
- 提供明确的对齐参照选择：画布、照片、留白区域、选中元素。
- 一次吸附只改变当前位置。持续保持居中或边缘距离使用显式锚定选项，避免拖动后产生隐藏约束。

### 水印比例与模板布局

- 默认以最终画布短边为尺度；设计短边为 1000 单位。字号 20 对应短边的 2%。
- 最终画布为 3000×2000 时字号为 40 px；6000×4000 时为 80 px。
- 右侧显示设计单位与换算后的导出像素；另提供固定输出像素模式。
- 位置保存为相对位置或显式锚点加偏移；不存预览屏幕坐标。
- 字距、边距、Logo 和效果参数遵循统一的缩放规则；画布缩放不修改这些值。
- 同一模板可包含横图、竖图布局，并共享视觉样式。正方形默认采用横图布局，可单张调整。
- 缺少对应方向布局时按比例与锚点适配，并检查越界、重叠，供导出前检查。
- 独立摆放与自动排列组分开处理：隐藏缺失字段时，自动排列组收拢间距，独立元素不自动移动。

### 参数与批量作用范围

- 分开保存原始拍摄信息、当前照片的手动覆盖值、模板中的字段绑定与样式。
- 参数缺失显示“未读取到”，可补填；提供恢复原值。编辑用于水印，不写回原照片。
- 默认编辑当前活动照片。照片多选代表批量操作目标，不自动改变右侧编辑的作用范围。
- 显式操作“应用样式到选中照片/全部照片”复制布局与样式，并按方向匹配模板布局。
- 套用样式保留各张照片的拍摄参数与手动补充值。公共信息批量填充使用独立操作。
- 如果批量套用会替换单张布局调整，先展示受影响数量，可选择跳过单张调整；本次操作支持整体撤销。
- 原图的取色与模糊背景逐张生成，不把当前照片的背景结果复制给其他照片。

### 字体与保存

- 支持选择系统字体及导入本地字体；字体列表可搜索，并提供样例预览。
- 单个字段可拥有独立字体，支持多选统一修改。
- 品牌 Logo 作为图片素材；型号、参数、签名文字作为文字元素。
- 模板保存布局、字段绑定、字体选择、背景与边框效果、分组关系及所需 Logo/自定义素材引用。
- 模板默认不保存某张照片的 EXIF 数值和单张手动覆盖值。
- 项目保存照片引用、每张调整、元数据覆盖值与当前模板快照；照片移动后可重新定位。
- 模板保存、另存为，以及项目保存提供明确区分。更新模板不静默覆盖已经打开的项目。
- 字体缺失时提示替换；素材资源需要持久化管理，不能依赖临时路径。

### 导出

- JPEG/PNG、原尺寸或指定长边、JPEG 质量、输出目录与命名规则。
- 正式第一版必须支持批量成品导出，提供元数据保留策略、独立 GPS 开关、PNG 压缩设置及尺寸预览。元数据保留与水印文字显示分别控制；完整规则见 `v1-scope.md`。
- 进度、取消、失败列表及失败重试；同名文件默认生成唯一名称，保护原图。
- 大批图片按需解码、顺序或受限并发渲染，完成后释放临时资源。
- 导出前展示图片数量、横竖布局情况、缺失字体/素材与排版异常，允许返回对应照片修改。

## 试用反馈修订（2026-09-21）

本轮已落实到交互原型：

- 内置模板支持本机更新，同时提供另存新模板。更新只写入当前横/竖方向，保留另一方向布局。
- 图层面板增加“添加参数”：常用拍摄字段、其他可读元数据与自定义文字。字段绑定随模板保存，套用时读取目标照片的值。
- 画布采用连续缩放，支持滚轮、滑块、数字比例、适应窗口，以及空格拖动平移。缩放只改变观察比例。
- “跟随照片”改为以照片比例向外扩展相框，顶部和左右保持相同基础留白，底部增加独立信息区。固定比例采用完整容纳并居中规则，不能同时保证所有边等宽。
- 画布中心使用蓝色实线，照片/留白/其他元素中心使用紫色点线，边缘使用橙色虚线，均带文字。吸附成功突出对应线并显示目标名称；画布中心优先于邻近元素边缘，增加释放缓冲减少抖动。

这些是可试用的实现，吸附手感与模板布局效果仍待用户反馈。正式应用范围与原型限制保持分开，详见原型说明。


## 第二轮试用反馈（2026-09-21）

本节更新上一轮交互规则：普通滚轮上下滚动画布，Ctrl + 滚轮以鼠标为中心缩放；基础留白拆为左右、上下两组独立数值；底部留白增加 1/3、2/3 吸附线与两行快捷对齐按钮。旧模板保持兼容。

后续模板采用四个可独立启用的参数区域，完整方案与实施边界见 [四边参数区域方案](frame-regions-design.md)。该方案目前未整体实现在原型中。


## 四边区域原型已接入（2026-09-21）

在上一节基础上，现已实现四区域开关/额外空间/默认方向、字段区域归属与局部百分比坐标、整行 ±90° 旋转、区域三等分及关闭恢复，并随模板保存和批量套用。上/下区占整宽，左/右区占照片高度；旧模板保留自由定位。

自动行列分组、中文逐字竖排与安全边距仍在后续范围。完整现状及核验记录见 [四边参数区域方案](frame-regions-design.md)。
