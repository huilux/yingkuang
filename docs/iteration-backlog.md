## 新功能方案

### 1. 缺失原图重新定位（P1）

- 场景：摄影师把素材移到移动硬盘，重启应用后继续上次排版。
- 操作：缺失照片保留在列表，提供“重新定位原图”；选定后展示新文件尺寸并恢复旧文档与文字覆盖。
- 状态：待做。先完成缺失数据保留，再增加重新定位入口。
- 边界：路径重复不创建重复照片；不同长宽比提示布局需检查；取消选择不改变会话；无法解码保留原状态。
- 验收：丢失→重新定位→编辑→导出→重启，文档、勾选和模板关联均保留。

### 2. 长边上限与小图不放大（P1）

- 场景：混合手机、相机和裁剪小图，一次输出用于分享的图片。
- 操作：在长边尺寸下增加“不放大小图”，预览实际成品尺寸；默认值需与既有“固定长边”语义区别明确。
- 状态：待做。前端尺寸估算、后端尺寸计算、设置恢复和预检必须一致。
- 验收：横图、竖图、小图与带边框图片的最终尺寸符合上限；原尺寸模式不受影响。

### 3. 导出耗时与结果记录（P2）

- 场景：大图编码时确认任务仍在运行，导出后知道花费时间与失败原因。
- 操作：进度显示已用时间和当前阶段；结果显示总耗时。暂不使用未经校准的精确剩余时间。
- 状态：待做。先保存本次会话结果；跨重启历史需明确容量和清除方式。
- 验收：等待、取消、失败都停止计时；长时间任务不因界面刷新丢失状态。

### 4. 导出预设（P2）

- 场景：重复切换分享图与原尺寸交付。
- 操作：命名保存格式、质量、尺寸、元数据、后缀及重名策略；目录由用户明确选择是否保存。
- 状态：待做。预设与相框模板分别管理，修改后显示未保存状态。
- 验收：预设 schema 版本化；非法数据拒绝；不会在切换预设时自动执行导出。

### 5. 批次筛选（P2）

- 场景：200 张照片中查找竖图、未读取相机参数或上次失败的项目。
- 操作：提供方向、缺失字段、失败状态筛选，以及只勾选当前筛选结果。
- 状态：待做。必须清晰显示“已勾选总数”和“当前可见数”，防止隐藏选择造成误导出。
- 验收：筛选不删除照片或编辑；导出范围和预检清晰；键盘可操作。

## 发布与回滚

- 每轮从上一验收提交建立 `codex/iteration-NN-*` 分支；不在验证失败时打标签。
- 修复提交示例：`fix(export): preserve output files and retry snapshots`。
- 新功能提交示例：`feat(export): add a no-upscale size limit`；新功能轮使用次版本号。
- 版本同步用 `npm run version:set -- X.Y.Z`，检查用 `npm run version:check`。
- 回滚定位使用已验证标签；已有文件和用户会话数据迁移必须向后兼容或保留原始备份。
