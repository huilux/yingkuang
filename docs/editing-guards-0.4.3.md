# 0.4.3 键盘与坐标输入验收

## 修复

- 选中可见水印后，在属性标签上按右方向键，标签会切换，同时水印意外右移 1 个单位。标签已经处理并阻止默认行为，但全局快捷键没有检查该状态。现在全局处理器尊重已处理事件，画布微调保持正常。
- 精确坐标输入允许 `1e308` 等 JavaScript 有限数，转换为原生 f32 坐标时溢出。它会进入编辑文档，导致导出拒绝、重启时会话被判无效。X/Y 输入现在在提交前检查原生可表示范围；超范围输入恢复旧值，合法画布外坐标仍支持。

## 验证

两项均先复现失败：标签导航将 x 从 830 改为约 831；超大坐标提交改变输入和文档。修复后：

- Chromium：标签导航不改变位置；X/Y 的正负超大值均被拒绝；负坐标可提交与撤销；画布方向键微调和撤销正常。
- WebKit：全部 23 项流程通过，包括拖动、精确坐标、多选、历史、弹窗、导出和恢复。
- 生产构建、版本一致性、TypeScript、29 项功能检查和入口预算通过。

证据：`scripts/editing-guards-regression.js`、`test-output/webkit-0.4.3.log`、`test-output/build-0.4.3.log`。原生渲染算法未改动，未重复性能基准。
