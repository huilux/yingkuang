# 照片裁切与旋转

画布工具栏点击「裁切与旋转」（已调整时显示「调整裁切与旋转」），在照片上拖动选区、八个边角手柄，或输入左侧位置、顶部位置、选区宽度和高度。支持自由比例、原图比例、1:1、3:2、4:3、16:9 及横竖切换。锁定比例时，输入宽高或拖动手柄会保持比例，允许像素取整产生的一像素误差。

左右旋转按钮每次旋转 90°，同步变换已有选区与比例方向，保留选中的像素。水平校正支持 −45° 至 +45°，滑块或数字输入可精确到 0.1°；滑块方向键微调 0.1°，Shift 加方向键微调 1°，Home/End 到达两端。「归零」只重置水平校正，保留 90° 方向调整；「重置为完整照片」同时清除旋转和裁切。

水平校正时，选框的位置、大小、比例和当前视图缩放保持固定，照片在选框内实时旋转并按需缩放以消除空白角。数字输入、步进箭头和滑块都会实时预览，无需点击图片或离开输入框；数字输入内按 Esc 撤销本次实时预览，空值等无效输入失焦时恢复进入输入框前的角度。实际保留像素会随自动缩放改变，输入区和底栏始终显示真实导出像素。所有预览和导出始终从原图重新变换，连续调整不会对已旋转图片重复采样。旋转中参考线保持水平和垂直，自动模式会将三等分加密为九等分，并强调中心线；也可固定为三等分、密集网格或隐藏。参考线和选框不会进入导出。

方向键移动选区，Shift 加方向键移动十像素；聚焦手柄时，方向键调整对应边角。空格加拖动或中键拖动平移，滚轮平移，Ctrl/Command 加滚轮缩放；下方按钮提供缩放和适应视图。视图变换不改变选区。

点击「应用调整」或聚焦裁切画布后按 Enter 生效。取消、关闭、Esc 均保留原来结果；数字输入框内 Esc 先取消当前输入。重置后仍需应用才生效。底部始终显示输出照片尺寸和应用/取消/重置操作。应用后主画布重新适应窗口。

调整仅作用于照片主体。相框、四边参数区及水印按选区尺寸重新排版，模糊背景和模板预览也来自旋转后的选区。原图尺寸水印仍描述原始照片，成品文件中的尺寸与方向元数据按实际输出生成。构图或横竖比例变化后可继续检查并调整水印位置。

裁切和旋转数据独立于模板，保存在每张照片的工作记录中，支持撤销重做、照片切换、重启恢复、缺失原图恢复和重定位。套用模板、更新模板和将当前画布批量应用到其他照片均不会复制或清除调整。

编辑器的固定选框通过统一缩放与居中偏移映射到旋转后的有效像素坐标，再保存至原有裁切字段，兼容已有工作记录。导出顺序为 EXIF 方向校正 → 旋转及自动去除空白角 → 裁切 → 成品缩放、相框和水印。选区坐标以旋转后的有效矩形为基准，边缘取最近像素，最少保留一个像素；旧工作记录缺失旋转字段时按 0° 处理。前端预览、尺寸估算、Rust 预检和实际变换共用几何规则及一致性样例。90° 整数倍直接排列像素，小角度旋转使用预乘透明度插值，避免透明 PNG 出现黑边。

原尺寸保留变换后的照片像素，再向外添加相框；指定长边针对含相框的成品，「不放大小图」以选区像素为限。每张照片分别导出自己的选区与角度，失败重试沿用冻结的原请求。原文件不修改。

## 验证

- `npm run build`：类型检查、42 项前端测试及启动体积检查。
- `npm run test:crop`：选区取整、八个手柄与比例、全角度有效区域检查、90° 循环选区保持、共享旋转尺寸样例、固定选框与输出坐标映射、会话迁移与失败重试快照。
- `cargo test --manifest-path src-tauri/Cargo.toml --lib`：52 项通过，6 项既有专项/压力测试默认忽略。实际 PNG/JPEG 编码覆盖全部八种 EXIF 方向、旋转与裁切、预检和编码尺寸；逐像素检查 90° 变换、空白角和透明插值，并验证裁切后的相框与水印。
- `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`。
- `scripts/photo-crop-regression.js` 和 `scripts/photo-rotation-regression.js`：Chromium/WebKitGTK 验证取消、比例、数字输入、键盘、缩放平移、参考线、±45° 端点、90° 循环、归零、高清加载延迟、预览方向、撤销重做、模板和批量应用、独立导出、重启与重置。WebKitGTK 同时回归恢复、重定位、导出及重试、批量样式、高清加载和模态窗口流程。
- `scripts/photo-rotation-interaction-regression.js`：检查输入框仍有焦点时的实时旋转、Esc 与无效输入回退、自由及固定比例选框稳定、视图缩放保持、应用前后像素一致和重新打开时结果不变。
- Chromium 真实鼠标/键盘检查数字步进、滑块、选区手柄及平移；1100×720 双主题检查，底部操作始终可见。

修正原因：旧实现将数字输入绑定到失焦提交，并在每次角度改变时按新的自动裁边边界重算选区、重新适应视图。现将选框坐标与旋转后的有效图像坐标分离，仅照片变换；角度输入启用实时预览。

浏览器导出流程使用 IPC 模拟，实际图像编码由 Rust 测试验证。本次未重新打包或安装 AppImage，未重跑 200 张批次与 9600 万像素压力测试。
