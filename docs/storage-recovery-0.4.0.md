# 0.4.0 存储备份与自动保存恢复

日期：2026-10-04。分支：`codex/iteration-06-storage-recovery`，基于 `v0.3.0`。

## 用户操作

桌面应用发现会话或模板库无法读取时，继续保留原记录，并在错误提示中提供恢复入口：

1. 打开“备份并恢复工作记录”或“备份并恢复模板库”。对话框列出当前可用内容数量。
2. 选择位置保存恢复备份。备份包含未改写的原始字符串，以及本次准备保存的当前内容。
3. 写入成功后，“恢复自动保存”才可用。确认后保存当前可见内容，后续编辑继续自动保存。

选图、文件选择器和模板管理仍使用既有工作流。默认模板保存失败另有“重试保存默认模板”。恢复入口用于桌面应用，浏览器预览不声称能够确认本地备份落盘。

## 数据保护

- 文件选择取消、备份写入失败或写入尚未完成时，不能启用恢复。
- 启用恢复前再次核对原始记录；若内容被其他窗口修改，要求重新备份，避免覆盖已知的新记录。
- 存储空间不足导致写入失败时，旧记录保持原值，备份仍保留，可释放空间后重试。
- 工作记录和模板库分别恢复，每次替换一个存储项。旧版模板库恢复备份同时保存 v1、v2 原始记录。
- 备份格式为 `yingkuang-storage-recovery` / version 1；`originalRecords` 保存原始字符串，`currentRecords` 保存准备启用的内容。它与模板库的常规模板备份不同。
- 无法解析的内容不会被自动修复；原始部分留在恢复备份中，当前可读取内容可以继续保存。

## 本轮修复

合法模板对象如果出现在错误分类中，或含未知内置 ID，原先会被合并过程静默丢弃。现在阻止自动覆盖并保留原文。重复 ID 的原始记录也保留；界面提供去重后可读取的模板，恢复时可备份原始记录再保存。
