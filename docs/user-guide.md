# 使用指南

本指南描述桌面应用的当前功能。平台下载见 [README](../README.md)。应用在本地处理照片，编辑和导出不会修改原文件。

## 界面主题

点击顶部的主题图标，依次切换「跟随系统 → 浅色 → 深色 → 跟随系统」，默认跟随系统。显示器、太阳、月亮图标分别表示当前模式，悬停可查看当前模式及下一次切换结果，也支持聚焦后按 Enter 或空格切换。选择会保存在本机，重新打开应用后继续使用；跟随系统时会自动响应系统主题变化。主题只控制编辑界面的显示，照片相框、文字颜色和导出结果仍按编辑设置生成。

## 导入与选择

点击「添加照片」选择 JPEG/PNG，或使用「导入文件夹」。也可以把照片或文件夹拖入窗口，文件夹会递归查找支持的照片。重复导入的照片会跳过，无法读取的项目会单独提示。导入、导出或弹窗操作期间，请等待当前操作结束再拖入。

「添加照片」与「导入文件夹」共享最近一次确认的导入目录，重启后仍保留；取消选择不会改变它。

左侧照片列表支持全选、反选、取消选择、移除已选，以及文件名和横竖方图筛选。筛选隐藏照片时，原有勾选仍保留；批量操作前检查界面显示的勾选范围与数量。

「新照片使用模板」只影响之后导入的照片，不改变已有照片的编辑结果。

## 相框与水印

右侧通过「模板」「相框」「水印」调整样式。相框支持纯色或模糊背景、横纵留白、四边参数区、圆角和阴影。照片阴影范围为 0–100，0 表示关闭。

水印文字可以来自 EXIF 拍摄参数，也可以手动填写。每个字段是独立图层，可以调整字体、字号、字重、颜色、透明度、位置和方向。手动修改参数不会改写原图 EXIF；可以恢复原始显示值。

点击文字或图层列表进行选择，Shift 点选可多选。多选支持整组拖动、参照对齐、等间距分布及批量样式。拖动时可吸附到中心、三等分线或其他图层，Ctrl/Command 可临时关闭吸附。

等间距和参照对齐会作为排版规则随模板保存，换照片后按实际文字尺寸重新分布并对齐。整组居中保留等间距，先居中再分布也会保留整组对齐；重复相同操作不会继续改变位置。整组拖动保留等间距并解除被移动方向的外部对齐；单独移动成员会解除被改变的排版关系。区域对齐与拖动吸附使用相同的安全边距。

旧模板没有记录的对齐关系需要重新设置：选择图层，执行等间距与居中，再「更新原模板」。不要仅保存旧坐标来代替这一步。

| 操作 | 方式 |
| --- | --- |
| 缩放 | Ctrl/Command + 滚轮，或画布缩放控件 |
| 平移 | 滚轮、空格 + 拖动或中键拖动 |
| 微调水印 | 画布聚焦后按方向键，Shift + 方向键移动更大距离 |
| 取消拖动 | Escape |
| 撤销 / 重做 | 顶部操作按钮；Ctrl/Command + Z 撤销 |

缩放百分比使用编辑器视口基准，100% 不表示原图像素的 1:1 显示。高清编辑图最长边为 4096px；导出独立读取原图，不受此预览上限限制。

## 裁切与旋转

点击画布工具栏的「裁切与旋转」。拖动选区或八个边角手柄，也可输入位置和尺寸；支持自由比例、原图比例、1:1、3:2、4:3、16:9 和横竖切换。

左右旋转按钮每次旋转 90°，已有选区随之变换。水平校正范围为 −45° 至 +45°，可精确到 0.1°；调整时选框保持固定，照片按需缩放以消除空白角。下方显示实际保留的照片像素。

- 「归零」只重置水平校正，保留 90° 方向调整。
- 「重置为完整照片」清除旋转与裁切，点击「应用调整」后才生效。
- 取消、关闭或 Escape 保留之前的结果；数字输入内 Escape 先撤销当前输入。
- 方向键移动选区；聚焦手柄时调整对应边角。Shift + 方向键按十像素步进。

裁切与角度按每张照片独立保存，支持撤销、重启恢复和原图重定位。套用模板或批量套用样式不会覆盖其他照片的裁切结果。

裁切或旋转使照片从横屏变为竖屏（或相反）时，会立即切换当前模板的对应布局，并保留照片上的局部修改；该操作可整体撤销。模板没有另一方向布局时继续使用现有布局。

导出依次执行 EXIF 方向校正、旋转、裁切，再生成相框和水印。「原图尺寸」保留变换后的照片像素并向外添加相框；「指定长边」针对包含相框的整个成品。构图变化后请检查水印位置。

## 字体

内置 Cormorant Garamond、Allura、龙藏体、Sacramento、Cinzel 和 Space Mono，均可离线使用。旧模板中的已移除字体自动映射到保留字体；个人模板数据不变。龙藏体负责中文回退，Space Mono 补充符号；缺少字形时预检会提示导入支持该字符的 TTF/OTF，避免静默导出缺字。需要原字体效果时，可离线导入原字体文件。字体来源和字重见 [字体说明](../public/fonts/README.md)。

在水印面板点击「导入字体」，可批量选择 TTF/OTF，每个文件最多 32 MB；不支持 TTC、WOFF 或 WOFF2。导入后再从字体列表选择，导入动作本身不会修改当前水印。相同内容的字体自动去重，损坏文件单独提示。

桌面应用将字体复制到应用数据目录，原字体文件移动后仍可使用，重启会自动恢复。模板备份只保存字体标识，不包含字体文件；换设备后需要重新导入同一字体。缺失字体会提示重新导入，导出预检会阻止静默替换。

旧模板的系统等宽字体 `monospace` 映射到内置 Space Mono，其他已替换的旧字体映射到对应内置字体。替换可能改变文字宽度，建议复核旧模板的排版。中文使用龙藏体回退；缺少字形时需导入支持该字符的字体。

## 模板与备份

无需导入照片也可以打开「模板库」，设为默认、复制、重命名、删除自定义模板或重置内置模板。当前编辑结果可更新原模板或另存新模板。

「导出完整备份」用于保存模板库；导入备份时，同名或同 ID 模板需要逐项选择覆盖、保留副本或跳过。完整备份可能包含本机照片封面，分享前请检查内容。

模板库支持筛选「官方模板」和「我的模板」。点击「检查更新」才会联网查询官方模板源，确认后下载安装；启动、编辑和导出不需要联网。更新不会上传照片、EXIF、本机路径或个人模板。

安装包附带五个基础模板，下载后的官方版本保存在本机。断网、下载中断或校验失败时继续使用已有模板。也可以下载[官方模板包](https://huilux.github.io/yingkuang/)后，使用「导入官方模板包」离线更新；官方模板包与个人完整备份用途不同。

官方更新只替换未修改的官方模板。本机修改、个人模板和默认选择会保留，已经导入照片的样式不随模板更新改变。官方撤下的模板会保留为本地模板；ID 冲突时保留个人副本并维护原来的默认选择。可查看原版差异与官方新版预览，使用「重置」才会清除对应本机修改并恢复当前官方样式。

「恢复上一版」回退官方模板版本，不清除个人模板、修改或已编辑照片。旧模板库会自动迁移，旧记录保留；存储损坏时阻止自动覆盖和官方更新，先导出原始记录或使用恢复入口。

「导出内置文件」用于维护官方模板，不等同于完整备份，详见 [发布内置模板](release.md#发布内置模板)。普通模板更新独立于软件安装包；需要新渲染能力时仍需升级软件。

## 导出

选择照片和导出目录，设置 JPEG/PNG、尺寸、质量或压缩方式。指定长边时，可以启用「不放大小图」，以实际保留的照片像素为限。

文件名后缀可手动输入，也可选择「使用相框名称」，例如 `原图名-旅行白框.jpg`。批量导出按每张照片使用的模板命名；模板名称中的保留字符会替换为下划线。重名文件可以自动编号或跳过，导出不会覆盖已有文件。

元数据可以不保留、保留基础拍摄信息或尽可能保留受支持信息；GPS 独立控制。部分无法安全迁移的元数据会省略，并在结果中提示。需要隐私保护时，选择不保留元数据并关闭 GPS；画面中的可见文字水印需另外检查。

批量导出顺序处理照片。取消后，当前正在处理的照片可能完成，未开始的照片停止处理。失败项可以重试；重试沿用原任务冻结的参数，后续编辑不会改变该任务。如果需要使用修改后的设置，请重新创建导出任务。

## 恢复与常见问题

- 原图移动或删除：上次会话保留编辑记录，可以重新定位原图或移除缺失记录。列表缩略图不能替代原文件进行正式导出。
- 模板或会话损坏：应用阻止自动覆盖，并提供原始数据备份及恢复入口。先保存备份再处理。
- 高清预览读取失败：保留缩略图并提示，检查原图路径和访问权限。
- 输出路径无效或过长：缩短文件名、后缀或目录路径，确认目标目录可写后重新导出。
- 字体库读取失败：在字体面板重试加载；缺失自定义字体时重新导入相同文件。

故障反馈请附应用版本、系统、复现步骤及脱敏样本，不要上传私人原片或完整个人路径。安全问题见 [安全反馈](../SECURITY.md)。
