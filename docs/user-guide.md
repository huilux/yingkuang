# 使用指南

照片在本机处理，编辑和导出不修改原文件。下载入口见 [README](../README.md)，版本变化见 [CHANGELOG](../CHANGELOG.md)。

## 安装

在 [GitHub Releases](https://github.com/huilux/yingkuang/releases) 选择对应系统和 CPU 架构的安装包。普通用户无需下载技术材料 ZIP 或 `Source code`。

- **Windows x64**：运行 EXE。测试包未做可信代码签名；缺少 WebView2 时，安装程序需要联网获取运行时。
- **Debian/Ubuntu x64**：安装 DEB，可使用 `sudo apt install ./下载的文件名.deb`。
- **Linux x64 AppImage**：添加执行权限后运行。文件名替换为实际下载的名称：

  ```sh
  chmod +x yingkuang_版本_linux-x64.AppImage
  ./yingkuang_版本_linux-x64.AppImage
  ```

  无法挂载时可加 `--appimage-extract-and-run` 运行。精简 Debian/Ubuntu 环境需提供系统图形运行库：`libgl1 libegl1 libgles2 libwayland-client0`。Wayland 会话优先使用原生 Wayland，保留 X11 回退。

- **macOS（实验性）**：Apple 芯片选择 ARM64 DMG，Intel 选择 x64 DMG。打开 DMG，将「映框」拖入「应用程序」。测试包只有 ad-hoc 签名，未经 Apple 公证；首次打开被拦截时参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，不要关闭全局安全保护。

DEB/AppImage 在 Ubuntu 22.04 CI 检查，Windows 在 Windows Server 2022 CI 检查安装与主题，两个 macOS 架构在 macOS 15 CI 检查 DMG 与窗口启动。其他环境、完整交互和升级需实机验证；macOS 首次安装及照片处理仍待实测，未承诺最低系统版本。

## 导入与选择

点击「添加照片」选择 JPEG/PNG，或「导入文件夹」递归导入；也可拖入照片或文件夹。重复照片会跳过，失败项单独提示。导入、导出或弹窗期间需等待当前操作结束。

两种导入方式共享上次确认的目录，重启后保留；取消选择不改变目录。左侧支持勾选、全选、反选和文件名、画幅筛选。筛选不取消隐藏照片的勾选，批量操作前检查已选数量。

「新照片使用模板」只影响之后导入的照片。移除照片或清空批次不删除原文件。

## 相框、文字与排版

右侧「相框」可调整纯色或模糊背景、横纵留白、四边参数区、圆角和阴影。「水印」可编辑 EXIF 参数或自定义文字，以及字体、字号、字重、颜色、透明度、位置和方向。手动覆盖参数只改变显示值，可恢复为原始值。

点击画布文字或图层列表选择，Shift 点选多选；支持整组拖动、对齐、等间距和批量样式。拖动可吸附中心、三等分线和其他元素，Ctrl/Command 临时关闭吸附。

### 对齐成行、列

选中至少两个可见元素，使用「元素互相对齐」中的：

- 「对齐成一行」：统一纵向中心，保留横向位置。
- 「对齐成一列」：统一横向中心，保留纵向位置。

基准是选区包围框的中心线，独立于「对齐参照」，不改变字号或自动均分间距。对齐后可继续等间距分布、调整范围、撤销或保存模板。隐藏元素、关闭区域或没有可用空间时不能对齐；完全重叠的元素需先拉开再分布。

### 等间距与分布范围

等间距、参照对齐和固定范围可随模板保存，换照片后按实际文字尺寸重新计算。整组居中保留内部间距，重复相同操作不会继续移动。整组拖动保留间距，解除移动方向的外部对齐；单独移动成员会解除受影响的关系。

「分布范围」只调整已有一行的占用宽度，或一列的占用高度；字号、方向和另一轴坐标不变。混排选区可先对齐成行或列，完全重叠时需先拉开。

百分比相对于整个画布，修改后按文字边缘等间距排列。滑杆实时预览，输入按 Enter 或失去焦点确认，Esc 放弃；一次拖动可一次撤销。

文字变长放不下时，实际范围会扩大，面板同时显示模板目标和所需最小值。若文字总尺寸超过画布，需减小字号或减少内容。区域在操作方向没有空间时暂时禁用，恢复留白后规则继续生效。「解除固定范围」保留当前位置。

旧模板未记录的对齐关系需重新执行对齐、等间距，再「更新原模板」。旧范围保留原有参照，重新调整后使用画布比例。

## 裁切与旋转

点击「裁切与旋转」，拖动选区或手柄，也可输入位置和尺寸。支持自由、原图、1:1、3:2、4:3、16:9 及横竖比例切换。

每次左右旋转 90°，已有选区随之变换。水平校正为 −45° 至 +45°，精确到 0.1°；选框保持固定，照片缩放以消除空角。

- 「归零」只重置水平校正；「重置为完整照片」清除全部旋转与裁切，应用后生效。
- 取消、关闭或 Esc 保留原结果；数字输入内的 Esc 先放弃当前输入。
- 方向键移动选区或聚焦的手柄，Shift 按十像素步进。

调整按照片独立保存，支持撤销、重启恢复和原图重定位。套用模板不会覆盖照片裁切。横竖构图变化时自动切换模板的对应布局并保留实际修改，无需再次点击模板；没有另一方向布局时沿用现有布局。

## 字体与主题

内置 Cormorant Garamond、Allura、龙藏体、Sacramento、Cinzel 和 Space Mono，均可离线使用。混排时中文、英文和数字按各段实际笔画垂直居中，保留英文连笔、小数点和日期分隔符。

英文字体缺少中文时回退龙藏体，缺少数字和符号时回退 Space Mono；仍缺字时预检提示导入支持的字体。旧字体名自动映射为内置字体，可能改变文字宽度，需复核旧模板。来源及字重见 [字体说明](../public/fonts/README.md)。

在水印面板「导入字体」选择 TTF/OTF，可批量导入，每文件最多 32 MB；不支持 TTC/WOFF/WOFF2。重复文件去重，损坏文件单独提示，导入后需从列表选择字体。

字体复制到本机应用数据目录，移动原字体文件后仍可使用，重启自动恢复。模板备份不含字体文件，换设备需重新导入同一字体；缺失时导出预检会提示，不会静默替换。

顶部主题图标循环切换「跟随系统 → 浅色 → 深色」，记住选择；主题只影响界面，不影响照片或导出。

## 模板与备份

没有照片也可打开「模板库」，设置默认、复制、重命名、删除个人模板或重置官方模板。当前编辑结果可更新原模板或另存新模板。

| 操作 | 用途 |
| --- | --- |
| 导出/导入完整备份 | 保存个人模板库；冲突时可覆盖、保留副本或跳过 |
| 检查更新 | 手动联网获取官方模板 |
| 导入官方模板包 | 从 [模板站点](https://huilux.github.io/yingkuang/) 下载后离线更新 |
| 恢复上一版 | 回退官方版本，保留个人模板、修改和已编辑照片 |
| 导出内置文件 | 供维护者 [发布官方模板](release.md#发布内置模板)，不等同于完整备份 |

完整备份可能包含私人照片封面，分享前应检查内容。

安装包自带基础模板，启动、编辑和导出不需要联网。仅手动检查和下载更新时联网，不上传照片、EXIF、路径或个人模板；断网、下载中断或校验失败时继续使用已有模板。

官方更新只替换未修改的官方模板，保留本机修改、个人模板和默认选择，不改变已导入照片的样式。撤下的模板会保留为本地模板，个人 ID 冲突时保留副本与引用。可预览官方新版，只有「重置」会清除对应修改并恢复官方样式。

旧模板库会自动迁移。数据损坏时阻止自动覆盖和更新，先导出原始记录或使用恢复入口。

## 导出

勾选照片，选择输出目录、JPEG/PNG、尺寸与质量。「原图尺寸」保留变换后的照片像素并向外添加相框；「指定长边」针对整个成品，可启用「不放大小图」。

后缀可手动填写或使用相框名称，例如 `原图名-旅行白框.jpg`；非法文件名字符会替换。重名时自动编号或跳过，不覆盖已有文件。

元数据可不保留、保留基础拍摄信息或尽可能保留受支持信息，GPS 独立控制。无法安全迁移的信息可能省略并提示。分享前检查元数据、GPS 和画面中可见的文字水印。

批量导出顺序处理。取消后当前照片可能完成，未开始的任务停止；失败项可重试。重试使用原任务冻结的参数，使用修改后的设置需重新创建任务。

## 成品预览与快捷键

点击顶部「预览」在窗口内查看成品，隐藏面板和编辑标记。支持滚轮缩放、百分比、「适应窗口」、拖动和方向键平移，Esc 或「返回编辑」关闭。

按 F11 从画布直接进入纯图片全屏，也可在预览中点击「全屏」。全屏隐藏工具栏、文件名和光标；Esc 或再次按 F11 返回编辑，恢复画布、选区和窗口状态。输入框、其他弹窗或拖动期间不触发快捷键，没有照片时不可进入。全屏失败时回到可关闭的窗口预览。

预览保留裁切、旋转和排版，编辑图最长边为 4096px；导出读取原图，不受预览上限或缩放影响。高清图读取失败时会显示缩略图并提示。

| 操作 | 方式 |
| --- | --- |
| 画布缩放 | Ctrl/Command + 滚轮，或缩放控件 |
| 画布平移 | 滚轮、空格 + 拖动或中键拖动 |
| 微调水印 | 画布聚焦后按方向键，Shift 加大步进 |
| 取消拖动 | Esc |
| 撤销 | 顶部按钮或 Ctrl/Command + Z |
| 纯图片全屏 | F11；Esc 或 F11 返回编辑 |

画布 100% 是编辑器视口基准，不表示原图像素 1:1。

## 故障与恢复

- **原图移动或删除**：会话保留编辑记录，可重新定位或移除缺失记录。缩略图不能代替原图导出。
- **模板或会话损坏**：先保存原始数据备份，再使用恢复入口。
- **高清图读取失败**：检查原图路径与访问权限。
- **输出路径无效或过长**：缩短目录、文件名或后缀，确认目录可写。
- **字体库读取失败**：重试加载，或重新导入缺失的字体。

反馈请附应用版本、系统、复现步骤和脱敏样本，不上传私人原片或完整个人路径。安全问题见 [安全反馈](../SECURITY.md)。
