# 0.2.0 导出体验改进

日期：2026-10-04。分支：`codex/iteration-04-workflow-improvements`，基于 `v0.1.3`。

## 小图不放大

“指定成品长边”下新增“不放大小图”。勾选后，主照片只保持原像素或缩小；包含边框的成品仍不超过指定长边。样例尺寸即时更新，设置随会话保存，失败重试保留原设置。

默认关闭，以保持旧版本固定长边的行为。原尺寸模式不受该选项影响；旧会话和旧原生请求缺少该字段时都按关闭处理。

前端估算与 Rust 预检、实际渲染遵守同一缩放规则。Rust 将预检和渲染共用的尺寸比例提取为一个函数，避免两处计算逐渐分歧。

实际 PNG 输出验收（测试边框：横纵留白 4，底部区域 13；指定长边 1200）：

| 主照片 | 最终输出 | 预检与解码尺寸 |
| --- | --- | --- |
| 600×400 | 632×484 | 一致 |
| 400×600 | 432×684 | 一致 |
| 400×400 | 432×484 | 一致 |
| 2400×1600 | 1200×919 | 一致 |

关闭选项时仍生成 1200px 长边；原尺寸模式开启与关闭的尺寸一致。

## 导出时间和取消反馈

- 进度显示已用时间，每秒更新。独立计时组件避免为了刷新秒数而重渲染整个编辑器。
- 结果显示原生队列测量的处理用时；计时范围不包含先前的预检和用户选择目录。
- 原生任务异常时使用界面侧实际等待时间。完成、取消和失败都清理定时器。
- 取消结果显示“已停止后续导出”和未处理数量，保留已完成文件的说明。
- 不显示未经校准的剩余时间；结果仅保留本次任务，跨重启导出历史仍是后续方案。

- 生产构建、24 项前端功能检查和入口预算通过。
- Rust 31 项通过，6 项显式压力/图像辅助测试未在常规测试中执行；新增原生测试实际编码并回读尺寸，旧请求兼容性和队列计时通过。
- Chromium/WebKit 验证旧设置默认值、尺寸预览、偏好保存和恢复、请求参数、成功/取消/异常三种计时退出路径；导出验证及原请求重试回归通过。
- 最小窗口 1100×720 下，模拟同时显示 200 个失败项目和 200 条提示，结果弹窗仍位于窗口内。
- Clippy `-D warnings`、Rust 格式与 Git 差异检查通过。

本轮不改变默认图片重采样和编码算法，既有真实性能数据见 [0.1.1](export-performance-0.1.1.md) 和 [0.1.2](export-reliability-0.1.2.md)。浏览器桌面交互使用 IPC 模拟；实际编码尺寸由 Rust 测试单独验证。
