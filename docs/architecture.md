# 架构

映框采用 React/TypeScript 界面、Konva 画布和 Tauri 2/Rust 桌面后端。前端管理交互、编辑文档和预览，Rust 读取原图、转换颜色并编码导出。平台状态见 [构建与发布](release.md)。

## 模块职责

路径均相对于仓库根目录。

| 模块 | 主要职责 |
| --- | --- |
| `src/App.tsx` | 照片批次、编辑状态、导入导出和界面协调 |
| `src/EditorWorkspace.tsx`、`src/EditorCanvas.tsx` | 按需加载画布、图层选择和拖动 |
| `src/canvas-camera.ts`、`src/selection-model.ts` | 视口变换、坐标换算、多选和排版 |
| `src/CropEditor.tsx`、`src/photo-crop.ts`、`src/photo-transform.ts` | 裁切交互、旋转与像素几何 |
| `src/use-editor-photo.ts`、`src/use-preview-backdrop.ts` | 高清编辑图和相框预览缓存 |
| `src/template-library.ts`、`src/builtin-template-catalog.ts` | 模板校验、备份冲突和内置模板合并 |
| `src/session-storage.ts` | 会话校验、迁移和恢复 |
| `src/font-library.ts`、`src/font-catalog.json` | 字体加载、导入与旧字体映射 |
| `src/export-workflow.ts` | 导出设置、任务快照、进度及重试范围 |
| `src-tauri/src/lib.rs` | Tauri 命令、原图检查、EXIF、预览和路径解析 |
| `src-tauri/src/export.rs` | 导出预检、图像变换、渲染、编码和队列 |
| `src-tauri/src/fonts.rs` | 内置与导入字体的解析、存储和查找 |

## 状态与交互

每张照片拥有独立编辑文档、参数覆盖、裁切和旋转信息。模板用于复制样式，不复制照片本身或照片调整。视口缩放和平移独立于编辑文档。

React 保存已提交状态，Konva 节点保存拖动中的临时位置。松手提交一次文档变更和撤销步骤；取消拖动不写入结果。多选对齐使用文字实际包围框，批量修改作为一个撤销步骤处理。

会话恢复依赖原图路径；文件丢失时保留排版并允许重定位。模板和会话在载入时校验，损坏数据先保留备份，避免自动保存覆盖。模板备份不嵌入自定义字体文件。

## 预览与导出

列表使用最长边 720px 的缩略图；当前照片按需生成最长边 4096px 的编辑图；相框背景使用受限的 1600px 预览缓存。原生高清解码串行处理，过期响应不覆盖当前照片。拖动水印和缩放不要求重新解码原图。

导出始终重新读取原图：

```text
原图 → EXIF 方向校正与 ICC→sRGB
     → 旋转及有效区域裁边 → 裁切
     → 成品缩放 → 相框、阴影、水印
     → JPEG/PNG 与选定元数据 → 临时文件 → 禁止覆盖地提交成品
```

前端预览、尺寸估算、Rust 预检及实际导出采用相同的几何约定，旋转样例由 `scripts/fixtures/photo-rotation.json` 共享。90° 整数倍变换直接重排像素，小角度旋转处理预乘透明度，避免透明边缘变黑。

模糊在 linearRGB 中处理；预览与导出统一阴影几何和文字字号换算。浏览器 Canvas 与 Rust 的抗锯齿可能有少量差异，通过渲染对比检查像素误差、文字边界和中心，而不承诺完全逐像素相同。

内置和导入字体在预览与导出端使用相同文件，不依赖系统 `fc-match`。旧字体名通过 `src/retired-fonts.json` 映射，缺失自定义字体会报错。可选 `vips` CLI 加速 JPEG 编辑图生成，未安装或执行失败时使用 Rust 路径。

## 导出安全与资源边界

前端先冻结所选照片和设置，Rust 再检查真实文件、尺寸、参数、目标路径和同批次重名。队列顺序处理照片并复用字体缓存，完成临时文件后禁止覆盖地写入目标。失败逐项记录；取消停止后续任务，重试使用原快照。

图像变换和画布像素数量受校验限制，以避免不受控的内存分配。缩略图、高清预览和导出共用原生方向与色彩处理。基础 EXIF 使用白名单复制，方向和尺寸按实际成品重写；受支持信息模式仍可能省略 MakerNote、旧缩略图、XMP/IPTC 等无法安全迁移的内容。

## 维护约定

改变几何、字体、相框或元数据行为时，同时检查前端预览和 Rust 导出；改变模板或会话结构时，保留旧数据迁移和损坏数据恢复能力。验证入口见 [开发验证](development.md)。

生产 WebView 使用 CSP 限制脚本和网络来源；开发模式单独放行本机 Vite 所需能力。打开导出目录通过 Rust 校验目标确实为目录，前端不授予通用 URL 或任意文件打开权限。
