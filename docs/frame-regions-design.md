# 四边参数区域方案

状态：四区域编辑、区域局部坐标、横排与整行 ±90° 旋转已实现于原型。本文同时描述后续设计；行列分组、中文逐字竖排、区域安全边距及专门的持续锚定开关尚未实现。

## 结构与空间分配

画布包含主照片，以及上、下、左、右四个参数区域。区域可独立启用、同时存在。照片内叠字和全画布自由定位仍然保留。

```text
┌──────────────────────────────────┐
│             上参数区             │
├──────┬────────────────────┬──────┤
│      │                    │      │
│ 左区 │       主照片       │ 右区 │
│      │                    │      │
├──────┴────────────────────┴──────┤
│             下参数区             │
└──────────────────────────────────┘
```

区分两个尺寸：

- **基础留白**：照片周围的间距。常用界面提供左右、上下两个数值；高级模式解锁上、下、左、右四边。
- **参数区额外空间**：为某一边增加高度或宽度。开启区域本身不自动改变已有尺寸，用户可以设置该区域额外空间。区域厚度包含该侧基础留白与额外空间。

例如：上下基础留白 4%，下区额外空间 12%，则顶部为 4%、底部为 16%。顶部也需标题时，可以再给上区增加 8%。左右区域同理。以上百分比统一以最终画布短边为基准。

跟随照片时，按照片原比例向四边扩展，不裁切照片。固定画布比例时，在预留四边空间后完整容纳照片，剩余空间均分到相应两边；界面分别显示设置值与实际留白。四边总需求过大时保留上一个有效结果，提示减少留白，不生成负尺寸。

**角落默认归上、下区域**：上、下区占画布整宽；左、右区只占照片高度，四区不重叠。关闭上区不改变角落归属，保证模板切换不会让其他区域突然伸长。特殊跨区文字可改为全画布自由图层。

## 区域内的排版

每个区域保存：启用状态、额外空间、文字安全边距、默认排版方向、辅助线分割方式。选中区域时高亮边界并显示名称，例如“右参数区”。

提供两种摆放方式：

1. **自由摆放**：字段可任意拖动，以区域为坐标参照。吸附仅调整本次位置；不会自动产生持续约束。
2. **行/列布局**：先添加行或列，再将字段放入其中；例如第一行品牌与型号，第二行焦距/光圈/快门/ISO。行内字段按顺序、间距、对齐方式排布，缺失字段隐藏后可自动收拢。

两行布局默认使用区域可用高度的 1/3、2/3 作为行中心；三行可用 1/4、2/4、3/4。这里等分的是行中心的参考位置，并不保证不同字号文字的外边距相等。若用户要求视觉等间距，使用按文字包围盒计算的分布操作。

当前原型的区域三等分按各区域完整矩形计算：上下区沿高度、左右区沿宽度，尚无单独安全边距。正式区域模型则在扣除安全边距后的可用矩形内生成参考线。

## 竖向排列的三种含义

| 模式 | 示意/用途 | 规则 |
| --- | --- | --- |
| 参数纵向堆叠 | 型号、光圈、快门各占一行 | 每个字段保持横排，从上向下排列 |
| 整行旋转 | 侧边一整条 `50mm · f/2.8 · 1/1600s` | 顺/逆时针 90°，保留参数内部阅读顺序；适合英文、数字、单位 |
| 中文逐字竖排 | 签名、标题、日期装饰 | 单字直立；中英数字混排另设规则，不能简单逐字符换行 |

左右区默认推荐整行旋转，方向可以分别设置。模板不能因位于左/右区域就强制旋转每个字段；字段可覆盖区域默认值。

## 自由编辑、吸附与绑定

- 参照选择扩展为：整个画布、主照片、上区、下区、左区、右区。
- 区域提供中心、边界、三等分等辅助线；只有线附近的对象参与吸附，不因字号变化把文字边缘误认作中心。
- 辅助线带区域名和比例，例如“右区宽度 1/3”“上区高度 2/3”。区域辅助线优先于邻近普通元素边缘。
- 横向区域主要沿高度生成行参考线；侧边旋转文字则沿区域宽度生成列参考线。沿长度方向仍可选择中心、两端对齐。
- 字段保存区域局部坐标 `(u, v)`，例如下区中的 `v=2/3`。用户也可显式选择“持续绑定到第二行”，此后区域尺寸变化保持该关系。
- 拖动时不静默改变字段所属区域。释放在其他区域时给出“移入上区/保持自由位置”的可撤销操作；也可在右侧直接改归属。
- 关闭含有内容的区域时暂时隐藏其内容并显示数量，不删除图层；重新打开恢复。需要保留跨区位置可先切为自由图层。
- 旋转或竖排后的文字度量、命中、吸附与导出使用同一套几何变换。

## 模板与混合批量

模板记录：四边基础留白、各区域配置、字体、字段来源、区域归属、局部坐标、可选持续锚定、行列布局及文字方向。原图 EXIF 与当前照片的手动覆盖值继续分开保存。

同一模板保留横/竖两套布局，区域使用稳定标识 `top/bottom/left/right`。默认让区域及文字方向跟随对应布局，不因照片横竖变化自动把上区换成侧区。缺少某个方向布局时可做区域比例适配，并提示检查；遇到重叠、越界或空间不足时引导单张调整。

老模板迁移：

- `padding` 映射到两组基础留白；已有 `paddingX/paddingY` 优先保留。
- `footer` 映射到下参数区额外空间。
- 原有画布坐标先作为自由定位保留，不自动猜测归属；用户执行“移入下区”时再换算局部坐标。
- 模板增加格式版本，迁移保留原文件/数据副本。

## 交付顺序与验收

1. 本轮已实现：横纵留白、底部三等分吸附及快捷对齐、常规滚动与 Ctrl 缩放。
2. 本轮已实现：四区域开关与尺寸、区域参照与局部坐标、文字整体 ±90° 旋转。
3. 然后：行列分组、持续绑定、缺失字段自动收拢、中文逐字竖排。

正式实现需用横图、竖图和不同分辨率验证：上/下同时存在、左右同时存在、四区同时存在、关闭后恢复、区域改宽后的坐标与文字方向、区域内两行/两列、模板保存重开、批量字段替换、预览与导出一致。


## 当前原型行为与核验

- “相框设置 → 四边参数区”提供开关、额外空间与默认文字方向。选择字段后可更改所属区域与单独文字方向；旧字段保持全画布定位。
- 移入区域会把所选字段的中心移到该区域中心；多选时保留字段中心之间的相对偏移。移回画布自由定位保留当时的物理位置与有效旋转方向。拖动不自动换区。
- 所属区域使用局部百分比坐标；改变区域尺寸后继续使用该局部位置。关闭区域时暂时隐藏所属字段，保留文字、位置与方向。
- 额外空间可记住关闭前的值；每个轴两侧留白合计不得超过画布设计短边的 90%，无效操作恢复前值并提示。
- 上下区占整宽，左右区占主照片高度；选中区域字段后显示其边界。对齐参照可选择四区，三等分按钮自动切换为两行或两列。
- 每个模板记录版本 2，区域配置与字段坐标/方向一起保存；首次保存新版时在独立 localStorage 键中备份原模板列表。自动画布的横竖模板方向按原照片决定，避免额外留白改变横竖分类；显式竖版/方形画布按其选择分类。
- 已验证 72 组几何组合、旧模板兼容、旋转文字边界与位移、区域关闭恢复、区域尺寸变化后的局部坐标。
- 浏览器中验证右区 1/3 对齐、旋转文字拖动吸附到右区 2/3、右区宽度从 9% 改为 18% 后坐标保留、关闭重开恢复、四边模板保存刷新与重新套用。
- 批量套用到第二张照片后仍显示其 f/5.6、60mm、1/320s；竖版画布预览导出显示完成。尚未验证正式原尺寸导出、色彩管理或原生 Arch 安装包。
