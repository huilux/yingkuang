# 0.5.2 参数选择体验验收

日期：2026-10-06。分支 `codex/iteration-12-parameter-picker`，基于 `v0.5.1`。提交 `fix(editor): make parameter picker keyboard accessible`。版本与标签 `0.5.2` / `v0.5.2`。

原「添加参数」弹层不响应 Escape；点击外部或把焦点移走后仍然遮住属性面板。优化前的浏览器检查明确返回 `Escape leaves the metadata picker open`。旧弹层的文字为 8–10px，参数值和来源挤在同一行；宽度固定为 300px，缺少适应面板的布局约束。

当前参数选择器提供如下操作：

- 打开后焦点进入搜索框；Escape、关闭按钮或完成添加返回触发按钮。处理过的按键不会清除画布选择或微移水印。
- 点击外部或焦点移出时关闭，保留用户已移动到的外部焦点；切换照片也关闭。
- ↑↓ 在搜索和选项间移动，Home/End 到首尾；Tab 保持自然顺序，Enter 使用按钮的原生激活行为。
- 搜索名称、值或 EXIF 标签；无结果时提供清除搜索。
- 每项分开显示名称、读取状态、来源和当前值。未读取参数说明添加后可手动补充，自定义文字标明手动输入。
- 主要文字提高到 12px；弹层跟随面板宽度、选项独立滚动，长值省略但可通过悬停查看全文；焦点周围保留空间。

验收证据：

- Chromium 完整新增流程通过，包括关闭、外部点击、外部焦点、空搜索恢复、首尾键盘导航、长元数据、添加一次与撤销。
- 实际浏览器按键 ↓、Enter 添加自定义文字通过；关闭后焦点回到「添加参数」。
- WebKitGTK 全部 26 项流程通过；最终焦点留白改动另行复测新增流程。
- 31 项前端功能检查、生产构建和入口体积预算通过，另有 9 项画布/选择模型检查通过。
- 1100×720 浅色、暗色目视检查通过。axe 记录零违规；滚动裁切边缘有 1 类对比度待定项。按实际辅助文字配色补检，暗色/浅色背景的对比度为 5.06:1 / 5.83:1，均高于 4.5:1。
- 证据位于忽略目录 `test-output/audit/`：`webkit-0.5.2.jsonl`、`webkit-parameter-final-0.5.2.jsonl`、`build-0.5.2.log`、`parameter-picker-*-a11y.json`、`screenshots/parameter-picker-*-min.png`。
