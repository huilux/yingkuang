# 0.5.7 界面布局与选择控件验收

日期：2026-10-06。分支 `codex/iteration-17-interface-controls`，提交说明 `fix(ui): align export fields and streamline window controls`，版本与标签 `0.5.7` / `v0.5.7`。

## 用户反馈与改动

| 反馈 | 证据与处理 |
| --- | --- |
| 导出选择框错位 | 修改前在 1100×720：格式/尺寸顶部 405/413px，后缀/重名处理 571/590.47px。原因是字段在网格中被拉伸，最后一个字段下边距不同。现在字段按内容顶部排列，网格内下边距一致；控件统一 36px 高，说明和校验错误不再改变相邻控件的起点。 |
| “编辑”按钮含义不明 | 原按钮没有任何操作，始终显示选中。已移除；保留真正的吸附开关及用途说明，宽窗口显示空格拖动平移提示。 |
| 只有名称的标题栏占空间 | 取消独立系统标题栏，把最小化、最大化/还原、关闭整合到应用顶部。应用顶栏由 64px 收紧为 48px，保留文件名、撤销、模板库及导出。标题空白/名称可拖动，双击最大化；窗口边缘支持八个方向缩放。窗口按钮在应用弹窗期间仍可操作。 |
| 选择框外观不统一 | 模板、方向筛选、导出、图层属性和模板导入使用统一下拉控件；选中勾号、活动行、箭头、焦点与禁用状态采用应用双主题。复选框和分段选择也统一选中样式，分段按钮提供 `aria-pressed`。 |

下拉框支持方向键、Home/End、Enter/空格提交、字符定位、Tab 离开、Escape 收起；Escape 不关闭外层弹窗，滚动或离开控件会关闭菜单。菜单保持在窗口内，长选项可换行；活动项仅滚动菜单自身，避免 WebKit 将外层表单一并滚动。选择框焦点下的方向键与 Delete 不操作画布。

## 额外发现：原图选择器大小写

GTK 图片过滤生成 `*.jpg` 等区分大小写的模式。旧版在原片目录中隐藏 `.JPG`，同一张照片复制为 `.jpg` 后可选择并导入。新规则覆盖 JPEG/PNG 扩展名的大小写组合，导入和重新定位共用，原图无需改名。最终安装包已导入 `PANA9432.JPG`，读取为 6000×4000，并保留独立的编辑记录。
